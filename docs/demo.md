# 2 分钟演示脚本

## 启动

```powershell
uv sync
uv run --env-file .env uvicorn content_agent.main:app --host 127.0.0.1 --port 8080
```

打开 `http://127.0.0.1:8080/`，页面会自动载入标准讲解场景并生成一轮结果。浏览器建议使用 1440×900 或更宽窗口，缩放保持 100%。

实时监听要求 `.env` 中有有效的 `BILIBILI_ROOM_ID` 和 `BILIBILI_COOKIE`。`config/agent.json` 的 `deepseek_enabled` 为 `false` 时展示规则版；改为 `true` 会润色候选话术，失败自动回退。

## 时间线

### 0:00–0:15 开场

- 说明这是直播辅助 Agent：输入直播阶段、弹幕、商品资料和互动信号，输出排序后的提词建议；后台指标是可选接入点。
- 指出左侧是控制台，右侧是阶段状态、调度记录和提词队列。

### 0:15–0:35 场景回放

- 保持“场景回放 / 标准讲解场景”，指出阶段时间轴停在“产品讲解期”，右侧显示阶段目标、剩余时间和下一阶段准备项。
- 三条提词分别来自价格问题、肤质问题和购买意向；分值由阶段、互动信号和事件共同决定，后台指标是可选输入。
- 展开“当前商品”，可以切换商品目录中的 SKU，验证不同商品的卖点匹配。
- 切换“阶段指令”到预热期或促单期，观察 AI 话术的语气和推荐动作随阶段变化。

### 0:35–1:00 促单冲突

- 切换到“促单冲突场景”。
- 场景处于促单期，同时有 3 次“油皮能用吗”同问、价格负面反馈和刷屏。
- 指出决策融合把肤质答疑排到价格促单之前，调度记录明确写出“同问/负面反馈触发答疑插播”。

### 1:00–1:45 实时监听

- 切到“实时监听”，数据源保持“B 站直播间”，点击“开始监听”。
- 左侧事件流会实时出现弹幕、礼物、舰长/提督/总督、醒目留言和进房/关注事件；进房会显示昵称和具体动作。
- 营收区同时展示礼物件数、礼物价值、醒目留言价值，以及舰长/提督/总督分别的件数和价值；礼物价值按 1000 金瓜子 = 1 元折算，银瓜子礼物计 0 元。
- 默认不会自动刷新提词。需要演示自动窗口时，勾选“自动刷新提词队列”，等待一个 10 秒窗口；队列上方会显示“实时 · 10 秒窗口 · AI 语义 · AI 生成”。
- 在左侧“阶段控制”手动切换到“促单期”，或在“当前商品”切换 SKU，点“立即分析本窗口”验证运行中更新。
- 录制时保持自动刷新关闭，队列会稳定不动；需要更新时点“立即分析本窗口”。
- 指出“在线”计数来自 B 站房间信息；购物车点击和转化率没有公开来源，页面不展示，也不使用示例值。
- 说明昵称只在页面展示，不会进入模型；模型收到的只是弹幕文本、商品事实和候选草稿。

> 如果录制时直播间没有弹幕，将数据源切到“离线模拟源”，并明确说明这是离线演示源；模拟源只用于演示，不代表真实直播数据。

### 1:45–2:00 收尾

- 查看“AI 决策摘要”，说明这是模型单独生成的本轮排序解释；下方“调度说明”则是规则引擎的冲突/合规记录。
- 展开底部“分析明细”，查看 AI 语义分析出的主题、相似问题、刷屏、负面反馈和购买意向；模型不可用时会显示关键词规则结果。
- 点击顶部“合规词库”，演示按风险等级、类别和关键词浏览词条与替代方向。
- 说明合规模块会对生成话术做词库预筛和语境过滤，命中风险会降级并给出替代方向。
- 说明实时事件通过 `/live/events` SSE 推送，所有分析仍走同一条 `analyze_async` 决策链路。

## 故障回退

- 页面没有数据：确认 uvicorn 已启动，先访问 `/health`。
- 实时监听启动失败：检查 `.env` 是否通过 `--env-file .env` 传入，Cookie 是否过期，房间号是否为数字。
- 直播间长时间没有事件：可能暂时没人发弹幕；继续等待或检查 B 站页面是否正常。
- DeepSeek 超时或报错：不影响结果，页面会显示规则版；录制前可先把 `deepseek_enabled` 设为 `false`。
- 不想录视频：可以直接运行
  `uv run --env-file .env content-agent --input examples/scene_conflict.json`，
  命令行会打印阶段、提词、合规和决策说明。
