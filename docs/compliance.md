# 合规预筛规则

`config/compliance_rules.json` 将 154 个唯一词条按绝对化表述、效果保证、化妆品医疗化宣称、需举证的资质/评价/数据、价格与稀缺促销信息五类维护。每个词条继承所在类别的风险等级和替代修改方向。

主播可以在页面顶部打开“合规词库”（`GET /compliance`），按风险等级、类别或关键词浏览全部词条和替代方向。该页面只读，数据来自 `GET /compliance/rules`，不替代实时拦截。

程序命中风险词时会暂缓原话术，降低优先级，并显示修改建议；没有命中只表示通过当前词库预筛，不代表法律审查通过。词语是否合法、是否误导消费者，仍取决于商品类别、上下文、证据及广告形式。商品资料应包含来源和核验状态，正式使用前由运营或合规人员确认。

## 语义过滤

词条匹配前先做归一化：

- Unicode NFKC：全角字母、数字和百分号转半角，例如 `１００％有效` → `100%有效`。
- 去掉空格、零宽字符和常见分隔符，例如 `全 网 最 低`、`全/网/最-低` → `全网最低`。
- 等价表达归一：`百分之百` → `100%`、`没有` → `无`、`无任何` → `无`、`蕞` → `最`。
- 词条变体：`100%有效` 同时匹配 `百分百有效`；`零风险` 匹配 `0风险`；`第一` 匹配 `第1` 和 `no.1`。
- 重叠匹配时保留最长词条，避免 `全网最低价` 同时报出 `全网最低`、`最低`。

匹配后再结合上下文判断是否真的构成风险表达：

| 语境 | 处理 | 示例 |
|---|---|---|
| 否定或免责 | 不命中 | `这款产品不是全网最低价`、`无法保证100%有效` |
| 转述或询问 | 不命中 | `有人问是不是全网最低`、`据说全网最低` |
| 句末疑问 | 不命中 | `全网最低吗？` |
| 固定搭配 | 不命中 | `第一步`、`第一时间`、`唯一编号`、`最高温度` |
| 明确断言 | 命中 | `全网最低价，赶紧下单`、`保证100%有效`、`最好的产品` |

`ComplianceModule.screen(text)` 返回 `hits` 和 `exempt` 两组可解释记录，包含词条、类别、命中片段、上下文和原因。`tests/test_compliance.py` 覆盖词条数量、词条唯一性、归一化、否定语境、询问语境、固定搭配和降级行为。

这一层是确定性规则过滤，不做模型推理，也不替代人工复核。它的目标是减少明显误报、统一等价表达，而不是宣称覆盖所有语义变体。

## 规则依据与边界

- [市场监管总局《广告绝对化用语执法指南》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/ggjgs/art/2023/art_64279265c896452f8f638f2de12b8003.html)：绝对化用语需结合广告内容、具体语境、误导后果及其他事实判断，并列出适用例外。
- [市场监管总局《直播电商监督管理办法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2026/art_ce66ea61fcec4583b5dbd677f470088b.html)：要求直播营销用语审核，禁止对商品性能、功能、质量、销售情况、用户评价、荣誉和资质作虚假或引人误解的宣传。
- [《化妆品监督管理条例》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_9f8b70e79a224f0baf940ab95ee0e0a.html)：化妆品广告不得明示或暗示产品具有医疗作用，不得含虚假或引人误解内容。

因此，该词表是保守的开发期风险筛查，不应宣传为完整的“广告法禁词表”或自动法律结论。
